## 📌 Descripción del Proyecto
El proyecto es la continuación del portfolio personal (TP1), convertido ahora en una Aplicación Multipágina (SPA). Implemente un sistema de navegación eficiente sin recargar el navegador utilizando `react-router-dom`. El layout se divide en un menú lateral estático (30%) y un área de contenido dinámico (70%).

## 🛠️ Tecnologías Utilizadas
- **React** (Librería principal)
- **Vite** (Herramienta de construcción)
- **React Router DOM** (Gestión de rutas y navegación)
- **JavaScript (Vanilla) & CSS3**

## ⚙️ Instrucciones de Instalación
Para clonar y configurar el proyecto en el entorno local, siguo estos pasos:

1. Clonar el repositorio:
   \`git clone https://github.com/jeerepazz/tp2-com7-sosa-paz-jeremias.git\`
2. Navegar al directorio del proyecto:
   \`cd tp2-com7-sosa-paz-jeremias\`
3. Instalar las dependencias necesarias:
   \`npm install\`

## 🚀 Instrucción para Ejecutar el Proyecto
Para Levantar el servidor local se usa el siguiente comando:
\`npm run dev\`

El proyecto estará disponible en `http://localhost:5173/`.
